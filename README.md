# 毛雨晴 · 个人作品集视觉改造

基于现有个人主页与真实项目素材制作的独立版本。原站点保持不变。

- 原站：https://mon24123.github.io/portfolio/
- 主要页面：`dist/index.html`
- 样式：`dist/style.css`
- 图片查看、主题切换与打印：`dist/app.js`
- 原有路见公开案例：`dist/bp.html`
- 内容来源与事实边界：`SOURCE_NOTES.md`

使用任意静态 HTTP 服务预览 `dist` 目录，无构建依赖。Sites 发布配置位于 `.openai/hosting.json`。该仓库默认私有；网页预览默认仅站点拥有者可访问。

页面优先展示碳循花园、GLIM、企业参访和路见，再展示运营、内容创作与实习经历。所有项目图片均来自原仓库，没有使用参考作品集的图片，也没有生成虚构项目素材。
